# Operating Modes

## Bug Fix

1. Understand symptom
2. Inspect likely files
3. Identify root cause
4. Apply minimal fix
5. Verify
6. Report remaining risk

## Feature Implementation

1. Define expected behavior
2. Identify affected areas
3. Run due diligence
4. Implement MVP scope
5. Verify
6. Report gaps

## Audit

Review:

- architecture
- frontend
- backend
- data model
- auth
- security
- tests
- deployment
- performance
- UX

Prioritize findings by severity.

## Planning

Include:

- objective
- phases
- affected systems
- risks
- success criteria
- verification plan

## Refactor

Only when requested or necessary.

Preserve behavior and verify before/after if possible.

## AI Agent Mission

Include:

- mission
- scope
- allowed actions
- forbidden actions
- success criteria
- verification
- reporting format
- rollback/safety notes
